# 音鳴らしますねぇ！

## Windows 常駐アプリ（おすすめ）

リポジトリ名は **OtoPlay**、アプリ名は **音鳴らしますねぇ！** です。

[Releases](https://github.com/Hayato-Akiduki/OtoPlay/releases) から Windows x64 用 ZIP をダウンロードし、展開して `OtoPlayer.exe` を起動してください。音声ファイルは同梱していません。

`dist/win-x64/OtoPlayer.exe` をダブルクリックして起動します。Windows x64 用で、.NET ランタイムを同梱しているため別途インストールは不要です。VB-CABLE ドライバーはインストール済みのものを使用します。

1. 出力先で **CABLE Input** を選びます。初回は見つかれば自動選択します。
2. 「＋ 音声を追加」でファイルを登録し、一覧から選んで「▶ 再生」を押します。
3. 受け取り側のマイクを **CABLE Output** に設定します。

### 音声ごとのショートカット

一覧で曲・効果音を選び、「キーを設定」を押します。Ctrl / Alt / Shift と、英字・数字・F1〜F12 の組み合わせを選んで登録してください（Ctrl または Alt が必要です）。例えば曲に Ctrl + Alt + F1、効果音に Ctrl + Alt + F2 を設定できます。

登録キーは一覧のファイル名の前に表示されます。画面を閉じて常駐中でも、そのキーで対応する音声を再生し、同じキーをもう一度押すと停止します。停止後は先頭から再生します。別の音のキーを押すと切り替わります（同時再生はしません）。リピート設定はすべての音声に共通です。

「キーを解除」で選択音の割り当てを解除できます。割り当ては自動保存されます。Ctrl + Alt + F9 / F10 は共通操作用のため予約済みです。他の音やアプリと競合するキーは登録できません。起動時に競合した場合は画面下部に表示されるため、別のキーを設定してください。

- × ボタン: 再生を続けたままタスクトレイに収納。
- トレイのダブルクリック: 画面を開く。
- **Ctrl + Alt + F9**: 選択している音声を再生／停止。同じキーをもう一度押すと停止し、次に押すと先頭から再生します。トレイ常駐中や他のアプリを操作中も使用できます。長押しによる連続切り替えは抑止しています。
- **Ctrl + Alt + F10**: 停止。
- トレイの右クリック →「終了」: アプリを終了。
- 音量・リピート・登録ファイル・出力先を `%LOCALAPPDATA%\OtoPlayer\settings.json` に保存します。音声ファイル自体はコピーしないため、移動・削除すると再登録が必要です。
- デバイス再読み込み・出力先変更時は再生を停止します。
- 自動起動の登録は行いません。音声出力の実機確認は受け取り側の入力メーターなどで行ってください。

### exe のビルド

.NET 10 SDK と NuGet への接続が必要です。

```powershell
dotnet publish OtoPlayer/OtoPlayer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o dist/win-x64
```

以下は以前のブラウザー版の説明です。

音声ファイルを指定した再生デバイスへ流す、ローカル専用の音声プレイヤーです。Node.js 18 以上と、音声出力切り替えに対応したブラウザー（Chrome / Edge など）が必要です。外部パッケージは不要です。

## 起動

このフォルダーで `npm start` を実行し、http://127.0.0.1:3210 を開きます。終了はターミナルで Ctrl+C。

1. VB-CABLE をインストールしておきます（必要なら Windows を再起動）。
2. 「出力デバイスを読み込む」を押し、必要なブラウザーの権限を許可します。
3. 出力先として **CABLE Input (VB-Audio Virtual Cable)** を選択します。
4. 音声ファイルを追加して「再生」を押します。
5. Discord / OBS / 録音アプリなどの入力（マイク）に **CABLE Output (VB-Audio Virtual Cable)** を指定します。

接続: 音声ファイル → このアプリ → CABLE Input → CABLE Output → 通話・録音アプリ。

停止・音量調整・リピート再生に対応しています。同時再生はせず、別の音を押すと切り替わります。ファイルやデバイス選択はページを閉じるとリセットされます。

## 困ったとき

- デバイス名を取得するため、ブラウザーによってはマイク権限が必要です。取得用のストリームは直ちに停止し、マイク音声は再生・保存・送信しません。
- CABLE Input がない場合は、Windows のサウンド設定で有効になっているか確認し、「出力デバイスを読み込む」を押し直してください。
- 出力デバイスが外れた場合は停止し、送り先の再選択を求めます。
- CABLE Input へ流した音は通常スピーカーからは聞こえません。受け取り側アプリの入力メーターで確認してください。
- 音声形式の対応範囲はブラウザーによります。WAV / MP3 などを使用してください。

VB-CABLE 自体のインストールはこのアプリでは行いません。

## 確認

`npm run check` で JavaScript の構文を確認できます。実際のルーティング確認は VB-CABLE を使い、受け取り側アプリの入力メーターまたは録音で行ってください。
